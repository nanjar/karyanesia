# Karyanesia development instructions

- Keep all Karyanesia application source code and development work in this repository: https://github.com/nanjar/karyanesia.git.
- Use docs/PRD-Karyanesia-v0.0.1.md as the product baseline. Record material scope changes explicitly.
- The investor and CTO presentation is at docs/presentations/Karyanesia-Investor-CTO-v0.0.1.pptx.
- Preserve tenant isolation, server-side authorization, immutable content versions, and auditable assessments required by the PRD.
- Never commit credentials, environment secrets, customer data, or temporary build files.
- Distinguish proposed targets from verified implementation and measured results.
- Use docs/design/CLEAN-GLASSIFY.md and its user-supplied PDF as the UI design reference. Preserve readable milk-white glass panels, pastel mesh backgrounds, and semantic blue/green/red accents. Never copy illustrative KPI values or implementation claims from mockups into live UI.
